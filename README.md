## 一页纸结论

调研基于三部分材料：ICLR 2025/2026 与 ICML 2026 全部投稿的原始数据（共 5.1 万篇，含评分、
状态、领域、关键词，我自己做的统计见
[analysis/results/conference-stats.md](analysis/results/conference-stats.md)）；
ICLR / ICML / NeurIPS / CVPR / ACL / AAAI 官方公布的政策与统计；以及对每个候选选题跑的
arXiv 查重。找不到权威数据的地方留空而不是猜 —— 例如 NeurIPS 2026 的投稿总量，网上流传
的"1.5 万"和"4 万"两种说法都没有可靠来源，本报告不采信。

**1. 盘子翻倍，但真正变化的是评审制度，不是接收率。**
ICLR 投稿一年从 11,677 涨到 19,814（+69.7%），接收率从 31.9% 降到 28.3% —— 只降了 3.6
个百分点，因为会议靠扩大录用规模吸收了增长。真正的变化是四个顶会在同一年、用四种不同
手段、各自独立地开始了实质性执法：ICLR 的 desk reject 从 70 篇（0.6%）暴涨到 905 篇
（4.6%），主因是自动化查出的**幻觉参考文献**；ICML 在投稿 PDF 里埋 LLM 水印抓违规审稿
人，连坐拒掉 497 篇论文；NeurIPS 用 Pangram 检测 position paper，desk reject 了 18.4%；
**ACL 在 camera-ready 阶段扫出 100 多篇已经录用的论文含虚假引用，全部拒掉。**
合规不再是形式问题，而且中了也不安全。

**2. 打分刻度换了，分数线落在平均 5.0。**
ICLR 2026 把评分从 {1,3,5,6,8,10} 改成等距的 {0,2,4,6,8,10}，4 分占了全部评审的 39.2%。
平均分 4.0 的论文只有 11.9% 中，4.5 是 28.6%，5.0 跳到 53.9%，5.5 是 78.8%。**决定命运
的是能不能把 4 变成 6，而不是能不能避免 2。**

**3. 评审分歧的作用会随位置翻转，不是单向的。**
控制住平均分之后：落在录用线**下方**时，分歧略微有利（有人愿意为你说话）；落在录用线
**上方**时，分歧明显不利。ICLR 2025 均分 6.0 的论文，评审一致组录用率 71.9%，分歧大的
组只有 57.3%。所以策略是两段的 —— 前期争取一个拥护者把你推过线，一旦过线就要消灭
反对意见。

需要注意的是，**ICLR 2026 的评分因安全事件被官方重置回了 rebuttal 之前的状态**，所以
2026 的分数分析反映的是初审分数，比正常年份嘈杂，也无法用来衡量 rebuttal 的效果。
上面这条结论用的是 2025 年（正常年份）的数据。

**4. 拥挤度和回报率是两回事，很多热门方向是负期望。**
`multi-agent systems` 份额一年涨了 305%，接收率只有 26.5%；`RAG` 接收率从 51.4% 崩到
29.7%，撤稿率 33.9% 全场最高。反过来，`safety`（+11.8pp 到 46.2%）、`quantization`
（+11.1pp 到 45.6%）、`continual learning`（+5.3pp）的接收率在整体下滑的年份里逆势上涨。
`reinforcement learning` 份额涨了 61% 还能把接收率从 41.3% 稳住到 42.8%，是唯一一个
"又大又稳"的方向。

**5. 理论和评测被系统性低估。**
ICLR 2026 里 learning theory 的接收率 46.3% 全场最高，每千篇投稿产出 23.3 篇 Oral —— 是
计算机视觉应用（7.7）的三倍。ICML 2026 里 theory 的 spotlight 率 12.4% 是一级领域最高，
computer vision 只有 5.4%。理论方向关键词的撤稿率低得离谱（learning theory 2.4%、
neural tangent kernel 3.7%），说明这类稿子极少在评审里被打穿。

**6. 得奖论文都在做同一件事：证伪一个大家默认成立的假设。**
ICLR 2026 两篇 Outstanding 是《Transformers are Inherently Succinct》和《LLMs Get Lost
In Multi-Turn Conversation》；ICML 2026 两篇是《The Flexibility Trap: Rethinking the
Value of Arbitrary Order in Diffusion Language Models》和一篇采样理论。没有一篇是
"我把 SOTA 又提了两个点"。

**7. "明显的空白"半衰期约两个月。**
我对每个候选选题都跑了一遍 arXiv 查重，结果推翻了自己的两个初始判断：RLVR verifier 覆盖
边界和 test-time scaling 收益转负，都在过去六周里被人做了；推理模型的 KV 压缩和低比特
量化三个月内至少有八篇。**会议数据和 arXiv 竞争强度之间存在约半年的时滞** —— 只看会议
接收率选题会系统性地慢半拍。

## 选题建议的一句话版本

在只剩 7 周的前提下，收益最高的不是启动一个新的大工程，而是挑一个 2026 年被广泛采用、
但从没被严格检验过的假设，用一组干净的受控实验把它证伪或划定边界。这条路子成本低、
不需要大规模训练、正好命中评审当下的偏好，而且是两个顶会今年给最高荣誉的那类工作。

查重之后仍然最空的两个具体切口：**在同等 token 预算下 agent memory 系统相对长上下文的
净收益到底是多少**，以及 **agent benchmark 的运行间方差有多大、多少已发表的"提升"落在
噪声内**。两个都是纯推理实验，7 周排期的执行风险最低。完整分析、拥挤度评级和应避开的
方向见 [docs/02-选题建议.md](docs/02-选题建议.md)。
