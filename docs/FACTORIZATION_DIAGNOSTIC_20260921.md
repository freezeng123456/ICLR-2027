# 可分离结构诊断协议

状态：运行前固定；独立于已经冻结的开发/确认参数选择，诊断结果不改变主确认集的参数或成功标准。

审查动机：当前全部因子属于坐标可分离类别。全量漂移按坐标分离，势函数按坐标相加，初始高斯和 Euler 噪声也是乘积结构。因此全量离散 Feynman–Kac 核是各坐标核的张量积；逐坐标粒子滤波针对相同的全量离散总体目标。当前联合重采样可能带来额外的坐标之间共同祖先和模式损失。

问题：普通混合算例的较大误差有多少来自选择联合重采样？一个利用已知独立结构的强基线是否显著改善当前结果？该基线是问题结构的标准利用方式，不作为新的原创算法。

固定对象：高斯、普通混合、弱混合，各使用采样种子 60–64；学习后目标使用训练种子 0、数据种子 500–504。共 20 个问题，每个比较全量联合滤波与全量逐坐标滤波，共 40 个单元。G=64、d=8、N=8192、K=512、U=20、float64，ESS 阈值 0.5。逐坐标方法最终分别重采样各坐标一次，形成均匀权重的联合样本；这一操作计入运行时间。联合方法保留其通常的最终权重。

指标：坐标 W1、真实目标 W1（学习问题）、符号组合总变差、标准化非对角二阶矩、固定 32 个投影的 W1、采样时间。保留每个问题，不用汇总跨不同误差尺度的模型族掩盖失败。

使用新机器，在主确认采样完成之后顺序运行，避免 GPU 资源竞争；上限包含在探索线 4 GPU 小时总预算内。此项主要检验现有 benchmark 的解释边界，不作为真实应用或一般非可分离模型上的验证。
