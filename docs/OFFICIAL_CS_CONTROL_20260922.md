# 官方 confidence-sequence 对照

本协议在读取官方CS对照的结果前固定，属于稀有反例开发实验的强基线补充。候选方法及其他五方法结果已经可见，因此本轮仍为开发研究。

依赖作者官方 `gostevehoward/confseq`，固定提交 `5ffe733ca2447a2e28c2c91f3b00086173f2ab2c`。直接调用 `betting_mart` 和 `predmix_empbern_twosided_cs`，不修改上游代码。官方库描述及相关论文：[ConfSeq](https://github.com/gostevehoward/confseq)；[bounded-mean betting](https://arxiv.org/abs/2010.09686)。

两个区域分别建立双侧时间一致置信序列，每个区域错误预算0.025，总预算0.05。对 betting 使用官方可预测 empirical-Bernstein 赌注和0.99安全截断，与候选方法的最大下注比例相同；正向财富关于候选均值单调下降，负向财富单调上升，分别求阈值的根并向外舍入1e-9。每16次查询检查一次，取历史区间交集。下一批查询选择经scale放大后区间宽度较大的区域。它允许把绝大多数查询分配给稀有反例区域。

官方纯Python模块在隔离依赖目录中使用NumPy1.26.4、SciPy1.13.1与multiprocess0.70.19；上游源代码保持原样。第一、第二轮候选开发使用NumPy2.5.3，因此查询指标可以比较，端到端计时需要统一环境后独立测量。

每个问题采用开发种子2000–2099，最多4096次查询，初始每层两个样本。官方基线可将初始样本计入置信序列，全部样本计入查询成本。保存查询区域、原始数值、各检查时刻区间、结论和软件版本。不得用未查询的数据选择区域。全局终止时最后一批16次全部计费，不按未知的批内首次通过点减少成本。

先核验所调用库的前缀不变性、反演根与完整财富的对应关系、区间范围和成本。最终比较时报告所有八个问题，包括不可判定与零差值错误。
