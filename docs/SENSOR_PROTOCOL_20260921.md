# 非可分离多传感器实验

本方案在任何传感器性能采样结果产生前固定。所有数据为公开可复现的合成数据，不涉及真实传感器部署。

## 目标与参考

每个问题包含十二个不同方向的传感器，状态维度为二维或八维。两个噪声设置使用模型生成器的 `ambiguous` 与 `regular` 参数；前者的噪声标准差为 0.8–0.95，后者为 0.35–0.43。传感器正符号概率交替为 0.65 和 0.8。状态和观测每次独立生成，参考后验枚举全部 4096 种符号组合，禁止按结果筛选目标或模式。

开发集合为每个维度/噪声设置的种子 1100、1101，共八个目标。确认集合为每个设置的种子 1200–1219，共八十个目标。不同设置共享种子用于配对比较，跨设置的推断采用种子分组抽样。它们不是八十个独立随机种子。

保留解析后验的混合权重、分量均值和公共协方差。每个目标独立产生两组 65536 个精确混合样本，第一组用于统一的距离参考，第二组估计参考抽样本身的误差尺度。参考采样不计入候选采样器时间。另将 16384 个精确混合样本作为可解诊断族的求解基线，时间包含符号枚举与采样，明确其指数复杂度。

## 候选与选择

扩散网格为 u=20(1-k/K)^2，初始分布为标准高斯，扩散系数为一，ESS 小于粒子数的一半时系统重采样。开发配置：全因子 (N,K)=(8192,1024) 和 (16384,2048)；锚点控制在这两个规模下分别使用 M=4、8；固定均值尾部控制和原始无偏随机权重分别使用 M=4、N=16384、K=2048。全部候选使用相同完整协方差因子得分。

退火 SMC 从先验开始，采用线性温度网格、每阶段系统重采样、三次 pCN 更新和一次全局符号翻转 Metropolis 更新。开发配置为 64 个温度下 pCN 系数 0.15、0.35、0.65，以及 128 个温度下系数 0.35；粒子数为 16384。提议全部使用精确观测似然计算接受率。

主指标为固定 32 个单位方向的平均一维 Wasserstein 距离，参考为预生成的第一组精确后验样本。每种方法另报告坐标 W1、解析均值误差、协方差误差、90%/95% 区间实际覆盖率、估计状态的均方误差、ESS 和实际运行时间。退火 SMC 与组合扩散使用不同的中间目标，最终目标相同；它是问题求解对照。

开发选择仅使用八个目标。分别在锚点候选和退火 SMC 候选内选择误差不高于精细全因子加 0.005 的最快设置；若全部未满足，选择误差最小者并记录未满足。确认固定比较精细全因子、选定锚点、固定均值尾部、原始无偏随机权重、选定退火 SMC 和精确枚举采样，共 480 个单元。所有方法按预先固定的随机顺序运行，完整输出保留。

确认阶段逐设置及总体报告配对重抽样区间，抽样单位为二十个确认种子，重复一万次。同精细全因子的联合判据是距离差值单侧 95% 上界不超过 0.005，同时时间比上界小于 0.8。对退火 SMC 和精确枚举分别报告，禁止忽略更强对照。有限参考样本的误差单独报告；置信区间反映当前种子范围，不构成普遍校准保证。

## 数学与运行核查

完整因子与尾部控制使用完整矩阵协方差递推，记录最小精度特征值及首个不满足严格正定的步骤。原始随机估计的全历史矩阵证书不作未经证明的简化，明确列为未证实。解析参考用直接贝叶斯似然、二维独立积分、不同实现的矩阵递推和恢复后样本重算核查。任务上限为两个 GPU 小时，并计入本轮四小时总上限。任何未完成单元保留状态，不计为完成结果。
