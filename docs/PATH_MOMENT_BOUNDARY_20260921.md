# 多步路径权重的一阶与二阶矩边界

这是在实现检查中观察到有限粒子偏差后的跟进诊断，不作为事先选定的性能确认集。

## 精确对象

使用既有 FactorModel 的高斯族，G=4、d=3，16 个等间距时间步从 u=1 到 u=0。每个坐标的全量 Euler 提议都是线性高斯递推。将整条提议路径写为 X=m+Lξ，其中 ξ 为标准正态向量，路径对数权重写为 XᵀCX+ℓᵀX+c，C 为包含时间步长的对角二次系数。

其 p 阶矩的高斯积分在矩阵 I−2pLᵀCL 正定时有限；矩阵具有负特征值时积分发散。有限时，用完成平方直接计算对数矩。这里研究的是无重采样的路径权重矩，不将结论直接扩展到自适应重采样后的方差。

## 确定性结果

| 坐标 | p=1 的最小特征值 | p=2 的最小特征值 |
|---|---:|---:|
| 0 | 0.3679553329 | −0.2640893342 |
| 1 | 0.3675610090 | −0.2648779819 |
| 2 | 0.3677065740 | −0.2645868520 |

三个坐标的一阶路径矩均有限，二阶路径矩均发散。精确的联合对数归一化常数为 3.6156738442，与逐步高斯倾斜递推一致。

使用 65536 个粒子和固定种子 759 的无重采样估计得到对数归一化常数约 3.518818，差值约 −0.096855。原始样本和各坐标输出完整保留。该单次偏差不能单独证明一般误差水平；精确二阶矩发散已经说明本配置不具备通常的有限方差蒙特卡洛区间依据。

另行记录 ESS 阈值为 0.95 的重采样实验，但其有限粒子偏差不由上述无重采样二阶矩结论直接解释。重采样后的可靠性需要不同分析。

## 实现检查

弱高斯验证配置将同一组分量方差变为 0.8+0.2v，均值和权重保持不变。独立矩阵积分验证其二阶矩有限；多步测试核查归一化常数、均值、方差和有界联合观测量。测试同时覆盖无中间重采样和每步按 ESS 阈值一进行重采样的分支。

精确矩阵积分实现为 `gaussian_path_moments_20260921.py`；测试为 `tests/test_factorized_baseline_20260921.py`；保留负面观测的运行脚本为 `run_path_moment_check_20260921.py`。原始诊断存放于 `work/path-moment-diagnostic-v2/`。诊断只能支持所给离散高斯路径的矩结论，不构成普遍粒子收敛定理。
