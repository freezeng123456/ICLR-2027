# 稀有反例的独立随机种子确认

状态：在本轮结果产生前固定。问题族来自开发实验，因此本轮只检验同分布的新随机种子可重复性，跨任务和真实应用泛化仍需单独验证。

## 固定比较

使用 `rare_problems()` 的全部八个问题、种子9000–9499、每单元4096次函数查询上限、总错误预算0.05。比较 growth、uniform、variance、paired 和作者官方 betting confidence sequence，共20000个单元。所有方法每16次函数查询更新设计与检查停止；最终不足16次时在预算终点检查。成对采样的一对样本计费两次。所有方法的前四次查询仅用于初始化学习，全部计入成本，证据过程从此之后开始。

候选方法的33个采样比例、32个下注比例、64个近期观测、0.02–0.98比例范围和0.99最大下注比例保持开发版本的数值不变。全部方法共用一个Python和NumPy/SciPy环境。官方 `confseq` 固定提交 `5ffe733ca2447a2e28c2c91f3b00086173f2ab2c`，原文件不修改。官方方法每个区域的双侧错误预算为0.025，总体0.05；候选方法直接比较积分差，每个方向预算0.025。

每个单元保存初始化样本、全部已查询区域与原始数值、财富或区间轨迹、实际查询数、设计更新次数、检查次数、用时、源代码提交及文件哈希。固定检查频率消除了批内提前停止带来的计费差别。

## 预先声明的主终点

主问题为 `rare_p0.002_b0.2`，它在开发阶段被选择。对 growth 与 uniform、paired、betting 的三项比较，分别报告成对种子查询差的单侧t上界，使用Bonferroni校正的0.05/3显著性水平。

这一研究候选进入应用实验所需的统计条件为：三项比较的平均查询数均降低至少10%，三项校正上界均小于零，且每项有效判定率的观测下降不超过5个百分点。判定率条件是探索的实用门槛，没有把它宣称为统计非劣效证明。全部八个问题与误判计数必须公布；不满足条件时不扩大此参数版本的计算。

稳健性分析固定使用20000次成对种子bootstrap、分析随机种子424242，报告每项查询差和判定率差的单侧上界。查询差的bootstrap上界也使用0.05/3校正；若其符号与主分析不一致，不把收益称为稳健。初始四个观测由所有方法相同的随机数调用产生，逐单元保存并核验跨方法一致。

查询数采用预算截断值，未完成判断的单元计为4096。不得把截断均值表述为无预算限制下的期望停止时间。误判率同时报告Clopper–Pearson区间，有限次零误判不代表真实误判率为零。零差值问题中的任何方向证书均视为误判。
