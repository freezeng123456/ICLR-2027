# Deterministic anchored affine tail control

## Interface

```python
from anchored_tail_20260921 import AnchoredTailModel

model = AnchoredTailModel(
    groups, dimension, family, device,
    sampling="without_replacement",
    parameters=params,
    grid=grid,
)
drift, potential = model.estimate(
    x, u, batch, generator,
    control=True,
    indices=indices,
)
```

The object is an `ExtensionModel` subclass and preserves the existing `estimate` and `exact` interfaces. `exact(x, u)` remains the original target-score calculation. Anchored control requires the without-replacement estimator, `control=True`, and the unbiased U-statistic potential branch. The supplied `u` must be one of the fixed grid values used at construction.

## Anchor construction

For each supplied grid time, the implementation computes `alpha`, `v`, the exact residual slope `a`, and the original affine intercept `b` from `variance`, `means`, and `weights`. It starts from

```text
x_star = total_b / (1 - total_a)
```

and performs exactly six deterministic Newton fixed-point updates. Each update uses the exact two-component logistic residual and its analytic derivative. The Newton denominator is lower-bounded by `0.2`; every step is clipped to `[-1, 1]`. The final intercept is

```text
b_new[g] = r_g(x_star) - a[g] * x_star.
```

Only factor parameters and the supplied grid enter this preparation. The parameters are predicted from each problem's observations. No reference integral, true theta, or evaluation metric enters the anchor construction.

The residual-value preparation charge reported by `cost_report()` is `7 * groups` per grid point: six evaluations during the anchor updates and one final matching evaluation. The confirmation driver separately records `6 * groups` analytic derivative evaluations per grid point. Wall-clock timing includes both charges, coefficient construction, and transfers. Parameter arrays are detached to NumPy `float64` exactly once during construction. Every grid entry stores Torch tensors for `a`, `b_new`, `sum(a)`, `sum(b_new)`, `sum(a^2)`, `sum(a*b_new)`, and `sum(b_new^2)`. Estimation reads this Torch cache and performs no NumPy-to-device conversion and no per-time `.cpu()` parameter read.

`cost_report()` reports `preparation_seconds`, including cache transfer and a CUDA synchronization when applicable. The experiment driver must time complete estimation with synchronization and add preparation to the reported sampling cost. Factor-equivalent preparation calls remain separately available through `preparation_calls`.

## Statistical scope

The new intercept changes the affine control while retaining the exact factor slopes. For a fixed anchor, the residual remains the exact score factor minus the new affine term, so the standard finite-population WOR drift and pairwise potential identities remain algebraically applicable. The residual remains bounded for the two-component logistic factor; its numerical bound and conditional variance can change with the anchor.

The implementation does not claim that changing the control intercept makes the kernel unbiased. The exact target score remains unchanged, while the WOR estimator identities are tested under the fixed anchored control.

## Validation and unverified scope

The test file checks exhaustive WOR subsets for drift and potential over heterogeneous randomly generated factors, three state points, and three grid times. It checks slope preservation, analytic endpoint residual values, probes at `x=+-1e6`, Gaussian zero residual with distinct nonzero factor means, preparation-cost accounting, Torch-native cache construction, and a fixed heterogeneous learned-like diagnostic seed pair `(602, 603)` whose factor subset is generated by random keys with `topk`. The conditional-variance result is reported only as a diagnostic and is not used to tune the six iterations or any other protocol parameter. These finite tests do not constitute a global boundedness proof.

CPU tests, CUDA multistep comparisons, checkpoint-derived conditional-variance diagnostics, a 24-cell CPU development study, and a 150-cell held-out H20 comparison have completed. The held-out study uses five trained models crossed with ten new datasets. Results and recovery checks are recorded in `docs/DUAL_RESULTS_20260921.md` and `results/dual_20260921/`. The algebraically equivalent batched-cache implementation is described by `docs/ANCHORED_EQUIVALENT_REPLAY_20260921.md`. These implementation and sampling checks do not supply a resampling-stability theorem or establish applicability to arbitrary neural scores.
