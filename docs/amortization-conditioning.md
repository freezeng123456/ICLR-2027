# 摊销条件数：先验的几何决定摊销贝叶斯推断会在哪里失败

## 一句话主张

一个摊销贝叶斯推断网络（PFN、NPE）在预训练完成后仍然残留的逼近误差，
不是均匀铺在隐变量空间上的，它集中在**预测分布很敏感、而后验又约束不住**的那些方向上；
这个方向和它对应的误差量级，可以在**开始训练之前**从先验本身算出来。

## 为什么这件事值得做

Müller 等人 2022 证明了预训练损失的最优解是先验 $P$ 下的后验预测分布。
Nagler 2023 进一步证明真实的 PFN 与这个最优解之间存在一项**不随样本量消失的偏差**。
到这里，已知的是「偏差存在」；未知的是「偏差住在哪里」。
2026 年那篇 TabPFN 不确定性分解的论文把这一点写成了原话：
我们目前缺乏任何关于 PFN 的上下文更新与真实贝叶斯规则接近程度的形式化理解。

这个空缺之所以要紧，是因为 PFN 与 NPE 的先验是人写出来的。
先验里放什么隐变量、上下文点怎么采样，都是设计者当场决定的，
而这些决定直接决定了训练出来的网络在哪些方向上可靠。
现在做这些决定没有任何判据，只能训完再看。

## 要算的对象

隐变量取对数坐标 $z$。给定上下文位置 $X$、查询点集 $\{x_q\}$ 与隐变量取值 $z$，
写下两个二次形式。

**证据信息量**：上下文对隐变量携带多少信息。$y \sim \mathcal{N}(0, K_z)$ 的 Fisher 信息矩阵

$$F_{ab} = \tfrac12 \operatorname{tr}\!\left(K_z^{-1}\,\partial_a K_z\; K_z^{-1}\,\partial_b K_z\right)$$

**预测敏感度**：把 $z$ 挪动一点，查询点的预测分布会移动多少。
单个查询点的预测分布是 $\mathcal{N}(m_z, s_z)$，它在 $z$ 上诱导的 Fisher–Rao 度量为

$$G_{ab} = \mathbb{E}_{y \sim \mathcal{N}(0, K_z)}\!\left[\frac{\partial_a m_z\, \partial_b m_z}{s_z}\right]
        + \frac{1}{2}\,\frac{\partial_a s_z\, \partial_b s_z}{s_z^{2}}$$

对 $y$ 的期望有闭式：把 $\partial_a m_z$ 写成 $u_a^{\mathsf T} y$，则第一项是 $u_a^{\mathsf T} K_z u_b / s_z$。
$G$ 在同一批查询点上取平均，才与「在同一批查询点上平均的预测差距」量纲一致。

网络要表示的是**后验**，所以分母是后验精度而不是单独的似然信息量：

$$A = F + \Lambda,\qquad \Lambda = \text{先验在对数坐标下的精度}$$

**摊销条件数**是广义特征问题 $G v = \lambda A v$ 的最大特征值：

$$\kappa = \max_{v} \frac{v^{\mathsf T} G v}{v^{\mathsf T} A v}$$

$\lambda$ 的单位是「预测 nat / 后验 nat」：每一个没有被网络解析出来的后验信息 nat，
要在预测分布上付出多少 nat 的代价。

## 先验项为什么必须在里面

只用 $F$ 当分母的话，$\ell$ 在数据里完全不可辨识的格子上 $F$ 近奇异，
$\lambda_{\max}(F^{-1}G)$ 会冲到 $10^4$ 量级，而实测误差是有界的——
因为那种格子上精确贝叶斯与网络都退回先验，两者一致，不产生任何差距。
加上 $\Lambda$ 之后 $\kappa$ 有界，同一张 96 格的表上动态范围收在 15 倍。

这一项还带来一条独立的判据：**数据约束不住的方向不会造成摊销误差，只要先验已经把它约束住。**
网络只在数据真正把后验推离先验的地方才需要干活。

## 预测（在训练之前就已写死）

1. **量级排序。** 若网络的失败可以刻画成「在后验度量下丢掉固定 $\varepsilon$ nat 的信息」，
   则超额预测 KL 满足 $\text{gap} = \tfrac12 \varepsilon\, \kappa$，即在 $\kappa$ 上过原点线性，
   斜率给出这一架构与训练预算下的信息缺口 $\varepsilon$。
2. **误差方向。** 把网络输出与精确混合后验分别投影回单个 $z$ 的 GP 后验族，
   两者之差 $e = \hat z - z^\star$ 在广义特征基下展开 $e = c_1 v_1 + c_2 v_2$。
   $v_i$ 归一到 $v_i^{\mathsf T} A v_i = 1$ 时 $v_1 \perp_A v_2$，于是分解精确：
   预测 $c_1^2/(c_1^2 + c_2^2) > 0.5$，零假设（误差在后验度量下各向同性）恰为 $0.5$。
3. **上下文设计的交叉。** 点数相同、先验相同，只改上下文点的位置：
   成对紧邻的设计用对内差值直接读出局部平滑度，把 $\ell$ 与 $\sigma$ 分开；
   均匀铺开的设计覆盖更广，但两者混在一起。
   $\kappa$ 给出的不是「哪种设计更好」，而是一条**随长度尺度移动的交叉线**，
   且交叉位置随点数移动。解析表上 $n_\text{ctx}=8$、$\ell=0.020$ 处成对设计的 $\kappa$
   是均匀设计的 0.36 倍，到 $\ell=0.278$ 反过来变成 1.35 倍。

## 必须击败的竞争预测量

这四个量在同一张表上形状彼此不同，所以实验能判别，而不是拟合。

| 预测量 | 对应的失败模型 |
| --- | --- |
| $\kappa = \lambda_{\max}(A^{-1}G)$ | 信息缺口集中在最坏方向 |
| $\operatorname{tr}(A^{-1}G)$ | 各方向的信息缺口相同 |
| $\operatorname{tr} F$ | 只看可辨识性。这是现有的 Fisher 诊断做法 |
| $\operatorname{tr} G$ | 只看输出敏感度 |
| 贝叶斯 NLL | 误差只跟随任务的绝对难度 |

## 受控实验

先验：$\ell \sim \text{log-}U[0.02, 2.0]$，$\sigma \sim \text{log-}U[0.02, 0.5]$，
窗口 $[-1, 1]$，RBF 核，信号方差 1。
长度尺度的范围横跨「远比点距密」到「比窗口还宽」，所以同一个模型内部就能扫出整条条件数曲线。

上下文设计逐任务随机（均匀 / 成对），两种设计都在训练分布内，评估时才是公平比较。
对内间距取成最小的 $\ell$：再小就要求 x 编码器分辨极细的间隔，那是架构分辨率的限制，会冒充几何效应。

差距的定义要严：网络只输出均值与方差，训练目标是高斯 NLL，
所以它能达到的最优就是精确混合后验的矩匹配高斯，两者之间的高斯 KL 正好等于网络付出的超额 NLL。
精确混合后验用 $(\ell, \sigma)$ 网格求积得到，求积误差必须比要测的差距小几个数量级，
否则测的是求积误差。

扫描的格子是 $\ell$（8 档）× $\sigma$（2 档）× $n_\text{ctx}$（8/16/24）× 设计（2 种）= 96 个。

脚本：`identifiability.py`（解析几何，不含训练）、`exp_conditioning.py`（先验、训练、
`--geometry-only` 打印训练前的条件数表）、`eval_conditioning.py`（差距、方向、四个预测量的回归）。

## 现有结果在这个读法下是什么

仓库里已有的 GP 实验（`docs/exp-log.md`）在这个框架下都是同一个量的特例：

- **A144 与 C 的对比。** 144 个长度尺度的单隐变量模型跟随精确贝叶斯的质量，
  明显高于组合数与训练步数完全相同的 12×12 双隐变量模型。
  单隐变量的 $G$ 与 $A$ 在同一维上，$\kappa$ 小；双隐变量存在「更平滑且更吵」这条脊，
  $\kappa$ 沿脊方向变大。
- **表格 PFN 上噪声轴掰得动、平滑度轴掰不动。** 能被上下文掰动的方向，
  正是网络确实解析出来了的方向，也就是 $\kappa$ 小的方向。
- **误差归因的 2×2 签名。** 先验里缺某个隐变量时，模型把数据用仅有的隐变量重新解释。
  这是「误差沿 $v_1$ 方向」在隐变量维数不足时的极端情形。

解析表给出的峰值方向本身也印证这一点：小 $\ell$ 处 $v_1 \approx (+0.64, +0.77)$，
$\log \ell$ 与 $\log \sigma$ 同向移动，正是「更平滑且更吵」那条不可辨识的脊。

## 与已有文献的位置

| 已有工作 | 做的事 | 没做的事 |
| --- | --- | --- |
| Müller et al. 2022 | PFN 的最优解等于先验下的后验预测 | 没有量化真实网络与这个最优解的差距 |
| Nagler 2023 | 证明存在不随样本量消失的偏差 | 没有刻画偏差在隐变量空间的位置 |
| Schmitt et al. 2024 等 | 在**测试期**从数据检测先验错配 | 需要观测数据；不预测训练前的可摊销性 |
| Gloeckler et al. 2023 | 用**关于数据 $x$** 的 Fisher 矩阵做对抗鲁棒 | 关心的是输入扰动，不是隐变量方向上的恢复质量 |
| sloppy model（Transtrum、Sethna 等） | Fisher 谱刻画参数组合的刚性与松弛 | 用在物理与系统生物学的模型评估与实验设计，没有接到摊销推断上 |
| SPN（Lv et al. 2026） | 已命名的错配下构造上下文做推理期修正 | 假设知道错配的形式；不涉及可摊销性 |

这篇的位置：$F$ 与 $G$ 都只需要先验与模拟器，不需要网络，也不需要观测数据，
所以它是一条**训练前**的判据，管的是「这个先验的哪些部分值得花算力去摊销」。
