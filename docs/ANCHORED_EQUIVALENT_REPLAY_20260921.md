# 代数等价缓存实现的计时复核

本项属于算法实现优化，使用已经固定的锚点方法及全部 50 个确认问题。它不增加独立确认数据的数量，不重新选择锚点、批量、粒子数、网格、模型或成功门槛。

动机是原实现重复构造两分量 softmax，并逐时间点传输小型缓存。候选实现将同一两分量残差代数化为 sigmoid 表达式，预先批量传输系数缓存。原始实现在源代码和结果中保留。

## 固定流程

原确认的 150 个单元全部完成之后，GPU 空闲时顺序复跑相同的三个方法：快速 full、快速 tail_fixed 和代数等价的 tail_anchored。对照继续使用原来的快速实现。执行顺序固定为种子 20260925，全部时间包括各自的准备、复制、采样和最终输出传输。复跑只能使用新机器四小时总预算中的剩余时间。

每个单元复跑后，与原确认的相同模型、数据、方法、随机种子比较全部原始粒子、归一化权重和对数归一化常数。最大绝对容差固定为粒子 1e-8、权重 1e-10、对数归一化常数 1e-8。任何单元不满足时，立即停止推广为等价实现，保留已有数据；其余结果不能被选择性包装成完整等价性通过。误差指标仍重新计算保存。

只有全部 150 个单元都通过数值等价性检查，才能将该计时结果解释为同一算法的另一种实现效率。原确认的精度结论继续成立；两组相同数据不合并成 100 个独立问题。重算配对交叉 bootstrap 时仍只有五个模型 × 十个数据集。

总体积分证书、原始源代码校验值、输入及训练检查点身份均复核。保存新源码、原始粒子、权重、计时、逐步记录、每个单元的等价性报告及完整完成凭证。不得根据中途结果重新选择容差或删去不利单元。
