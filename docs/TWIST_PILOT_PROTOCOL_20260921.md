# 高斯尾部路径提议开发协议

冻结前状态：路径密度恒等式与后向 Gaussian 递推已通过单元测试，真实任务收益未知。本协议只产生开发证据，不能代替独立确认。

目标使用传感器生成器的全新数据种子 1300、1301，维数 2、8，ambiguous、regular 两种噪声强度，共八个目标。与已有确认集 1200–1219 和主线确认集完全分开。参考来自 4096 个符号分量的精确混合，含两组独立 65536 样本。

固定比较七个配置：三个单一/双分量 Gaussian 提议（mean、anchor、mirror），均使用全因子目标、8192 粒子、1024 步；mirror 的 16384 粒子、2048 步；mirror 提议搭配锚定批量 8 的随机目标，8192 粒子、1024 步；全因子原提议 16384 粒子、2048 步；前一开发集选择的退火 SMC（16384 粒子、64 阶段、pCN 步长 0.15）。总计 56 个任务。

所有路径提议不作中间重采样，保留每个粒子的最终未归一化对数权重。混合提议必须使用完整混合密度分母。时间包括因子参数准备、参考递推和采样；共同参考答案生成不计入。随机执行顺序固定为 20261002。

CPU 或 GPU 使用必须准确记录，禁止混合比较两种设备耗时。GPU 启动前必须空闲，每个任务前后记录全部 GPU 进程；出现额外进程则停止本研究任务，不终止其他任务。运行上限三十分钟。新增 GPU 用量计入本轮四小时预算。

筛选门槛：全因子目标的候选平均 32 方向投影 Wasserstein 距离不超过全因子基线加 0.005，且包含准备的平均耗时小于基线 0.8 倍。随机批量目标另列，不混作同一目标的算法比较。若没有全因子候选同时通过两个门槛，停止本轮扩大实验，并保留全部开发结果；若有通过者，再冻结独立确认协议及新种子。
