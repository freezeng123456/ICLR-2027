## 计算边界

新服务器使用一张 H20，单个采样进程；本轮新增 GPU 实验总预算最多四小时。原服务器已有训练任务继续运行，仅使用最多四个 CPU 线程完成独立数值检查；如果 GPU 自行空闲，可以承担同一预算内的新实验。启动记录、源文件散列、完整输出、结束状态和本地恢复检查均需保留。

## 学习后验的独立质量与成本检验

固定五个已有训练模型，训练参数不变。开发数据使用模型 0、1 与数据编号 800–803，共八个问题。确认数据使用模型 0–4 与数据编号 900–919，共一百个模型/数据组合，其中只有二十个独立数据集和五个独立训练模型。

开发设置共九种：全因子与按坐标全因子采样各使用 N=32768、K=2048；固定尾部斜率的锚点控制使用 M=4、8、16，分别配合 (N,K)=(8192,1024)、(32768,2048)；另加 M=4、N=32768、K=4096。每次采样包含独立准备时间、设备传输、重采样和结果传回时间。开发集合上选择平均 W1 不超过全因子加 0.002 的最快锚点设置；如果全部未达到，只选择误差最小的设置并明确标记开发要求未达到。

确认阶段固定比较全因子、按坐标全因子、原有锚点 M=4/N=32768/K=2048，以及开发选定的锚点设置。相同配置仅运行一次。采用配对的二维重抽样：训练模型和数据集分别抽样，然后取笛卡尔积，重复一万次。成功要求仍为 W1 差值单侧 95% 上界不超过 0.002，时间比单侧 95% 上界小于 0.8。对全因子和按坐标全因子分别报告，任何更宽泛的优势必须通过强基线比较。旧确认数据不参与此次参数选择。

## 相关变量的多传感器推断

状态服从标准高斯先验。传感器观测是状态在不同方向上的投影，叠加随机正负符号和高斯噪声。每个观测对应两个具有相同完整协方差的高斯分量；不同传感器的协方差通常不可交换。联合后验通过符号组合枚举得到有限高斯混合，提供精确的目标密度、均值、协方差和投影分布。二维数值积分作为独立检查。

模型和数学证书通过单元测试后，固定非可分离实验的配置与数据编号，再执行确认采样。保留全因子扩散、随机因子扩散、锚点控制和使用目标密度的退火 SMC 对照。精确枚举作为本诊断族的参考求解器，必须报告它的成本与指数复杂度；禁止将小规模可精确求解问题上的实验表述为实际部署收益。
