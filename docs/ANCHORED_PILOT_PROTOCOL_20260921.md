# 锚点控制的完整采样开发诊断

状态：在采样前固定；这是局部方差诊断之后的开发实验，不作为独立确认结果。

当前原机器 GPU 被其他任务占用。本实验在原机器使用一个低优先级 CPU 进程，显式隐藏 CUDA，不干预其他任务。计算时间上限一小时。CPU 时间记录用于复现，不据此声称 GPU 加速。

对象：训练种子 0、1 × 数据种子 600–603，共 8 个学习后目标。三个方法为 full、tail、tail_anchored；G=64、d=8、N=4096、K=1024、U=20、M=4、ESS 阈值 0.5、float64。每个问题共用配对种子，固定随机执行顺序，共 24 单元。锚点规则保持六次 Newton 更新、步长截断 1、曲率分母下限 0.2；沿用已有控制的精确尾部斜率。

所有单元报告总体积分证书、学习后目标 W1、真实目标 W1、联合符号总变差、非对角二阶矩、固定投影 W1，并保存原始粒子、权重、参数、数据、参考积分、逐步诊断、源码和检查点校验值。控制准备耗时额外加入采样耗时。采样运行不使用真值或参考积分计算控制；参考积分只用于评估。

本组数据已经用于局部方差诊断，因此结论限于开发证据。没有调整参数或挑选最好种子，也不替代原先固定的 80/300 单元 GPU 当前线方案。后续推广需要新的确认数据和同一 GPU 上的公平计时。
