# 有限错误概率下的概率积分符号判定

日期：2026-09-22。研究状态：候选理论与机制实验；尚无应用收益或论文新颖性结论。用户授权在概率论范围探索新方法，并使用既有 SCNet 资源。本文件在读取本次实验结果前固定。

## 问题与候选贡献

给定可计算的未归一化后验密度及两个行动的有界损失，判断后验期望损失之差的符号。应用目标是降低获得可靠行动结论需要的昂贵函数评估次数。计算中的错误决定概率、后验模型本身的误设、真实世界行动风险是三个不同概念。

候选贡献是针对序贯证据增长优化重要性采样分布，并给出与最小方差分配的精确区别。现有重要性采样、test martingale 和 anytime-valid inference 为基础工具，不能各自作为新贡献。相关工作审查、非理想提议分布、实际应用和端到端耗时仍需验证。

## 两个数值层次

1. 解析机制检查：正负区域上的理想重要性分布，比较闭式最优分配与独立数值优化。允许使用真实积分的 oracle 只检验数学机制，不参与实际算法比较。
2. 可实施的有界分层积分：每个区域内函数值来自已定义的 Beta 随机变量，算法只观察被查询的值及公开上界。真实均值只供外部评估器使用。初始每区域查询两个值，成本计入总预算；每32次查询根据此前样本更新提议和赌注。

第二层具有明确的合成任务范围，不称为真实后验应用、实际 GPU 加速或完整研究成果。区域内独立抽样可用是额外结构假设。

## 比较与计量

三种方法共享完全相同的证据过程、赌注候选集合、初始样本、支持集保护和更新频率：均匀分层、经验二阶矩最小方差分层、经验对数证据增长最优分层。最小方差方法使用区域内二阶矩，不能用均值近似替换较强基线。

每次赌注和对数增长优化使用每区域最近64个真实观测，以限制计算开销；最小方差提议使用全部历史观测的二阶矩。该计算近似不影响证据有效性的证明，但实际收益必须包含优化耗时。所有方法的初始观测均不计入证据财富，只计入查询成本。

每次重复的两侧错误预算总和为0.05；单侧达到40的证据阈值才报告结论。最多4096次函数查询；未判定的运行作为删失数据保留。比较有预算截断的平均查询数、判定比例、错误结论比例、配对差值与不确定性。保留每一次提议、赌注、重要性权重和累计证据。

开发问题固定为：正负均值比1、1.2、2、9、100；相同区域内 Beta(8,2)；另有正向高方差 Beta(0.4,0.1) 与负向 Beta(8,2) 的均值比2、9；交换正负区域产生镜像问题。机制检查单独包括更大的比例。开发重复编号0–99；确认编号10000–10999在开发通过前不运行。

通过条件：开发中至少两个非零问题相较最小方差基线降低平均总查询数20%以上，配对区间支持收益；总体判定比例不得下降超过2个百分点。零差值检验报告错误率及二项区间，不把有限重复零错误写成证明。满足条件后仍须应用实验和创新性审查，才考虑继续投入 SCNet。
