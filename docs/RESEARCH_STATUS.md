# 研究状态：小批量组合扩散的可积性

日期：2026-09-09。论文为 `Integrability of Subsampled Compositional Diffusions`，正文、证明、图表及参考文献位于 `manuscript/`。当前为完成研究稿，尚未投稿。

## 科学问题与结果

组合扩散把多个因子的 score 相加。减少每个步骤读取的因子数量可以降低计算量，但 Feynman–Kac 修正需要把随机势放入指数。瞬时势无偏和有限均方误差都不能保证指数权重的总体积分有限。

本文对指定的 weighted Euler 算子给出可执行判定：标量 Gaussian 因子的普通独立有放回估计，只需在每一步递推两个极端常量批量的可达方差；这个判定与任何有限批量大小无关。任意 affine control 的扩展只需检查每个因子对应的常量批量。

四因子一步反例的全量分母为 `2503/3195 > 0`，全抽最强因子的批量分母为 `-167/1065 < 0`。后者对每个有限批量大小都有正概率。因此增加批量可以同时降低局部误差、提高有限粒子的 ESS，而总体归一化常数仍然无穷大。该结论明确依赖独立有放回抽样；附录中的无放回子集比较全部可积。

对于各因子内部使用相同分量方差的 Gaussian mixture，精确保留尾部二次系数的控制变量与全量更新具有相同的严格可积域。可积性不保证准确采样。普通八维 mixture 的全量和尾部控制都出现严重的联合模态遗漏，论文如实保留这些结果，没有普遍速度或精度优越性的主张。
