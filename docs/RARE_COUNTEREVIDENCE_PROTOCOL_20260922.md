# 稀有高后果区域的查询分配

这是在首轮有界分层开发结果之后提出的第二项开发协议。首轮随机混合方法没有超过确定性成对分层和已知上界基线；确认实验保持关闭。新开发问题检验另一项明确假设：当负向贡献由稀有高值主导时，确认正向结论所需的主要工作可能是排查反例区域。

固定正区域为 scale=1、Beta(8,2)，期望贡献0.8。负区域使用 Beta(p,1-p)，其中 p 为0.002或0.02；负贡献期望取0.2、0.4、0.8、1.2，scale=负贡献期望/p。保留两个零差值问题和两个负差值问题，不只选择正向成功任务。每题每方法100次开发重复，随机种子2000–2099，每次最多4096次真实函数查询。算法只能读取样本和公开scale，不能读取生成器的Beta参数或真实均值。

方法、证据阈值、每次更新最多64个历史值、初始查询和五种基线与首轮一致。全部原始轨迹保存。重点比较总查询、判定率和错误率。函数评估成本与本地运行时间分别报告。若出现收益，仍须加入逐区域均值 confidence sequence 与现代两臂固定置信度识别基线，之后才能决定是否开展应用实验。

这些新问题属于假设生成后的开发集。任何正向结果均不能替代预先隔离的确认集，也不能作为真实应用收益。
