# 相同粒子与步数的强基线检查

这是在主线确认结果已经可见后提出的公平性检查，不能算作新的独立确认数据。使用同一组五个训练种子、数据种子 900–919，共 100 个目标。

三个方法固定为：全因子、逐坐标全因子、已选择的锚定批量 8。全部使用 8192 粒子、1024 步，以及完全相同的原始数据和配对种子。锚定方法重放的粒子、权重、归一化常数必须与原确认输出相符，误差超过数值容差即停止。

共 300 个任务，执行顺序固定为 20261003。时间包含各自的准备和返回结果，三者在同一台 H20 上重新计时。每项任务前后检查 GPU 进程数，出现其他 GPU 工作则停止本研究任务。运行上限二十分钟，计入本轮四 GPU 小时预算。

结果用于区分：减少计算配置带来的收益，与随机因子算法本身带来的收益。配对两因素 bootstrap 与原研究相同，重复 10000 次。W1 容差 0.002、时间比 0.8 只作为沿用的诊断标准；此检查本身是事后增加的，不重新描述成预注册确认。
