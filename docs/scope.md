# 研究范围与证据要求

## 科学问题

有限容量、有限训练预算的 PFN，在自身先验正确时，对后验预测的近似误差如何随上下文长度、
训练预算和先验结构变化？这部分误差是否造成可测量的选择性预测代价？

现有模型是自训的小型 Transformer，使用 Gaussian mean/variance 输出头。
GP 与跳变过程提供可计算的后验参照。向 TabPFN、TabICL 或 TabDPT 的外推需要独立实验。

## 数学定义

给定任务上下文 D 与查询 x，真实后验预测记为 P，均值 m、方差 v。
网络输出 Q=N(a,b)，矩匹配参照 G=N(m,v)。有限二阶矩且 b,v>0 时：

\[
\mathbb E_P[-\log Q(Y)]-\mathbb E_P[-\log G(Y)]
=\mathrm{KL}(G\Vert Q)
=\frac12\left[\log\frac bv+\frac{v+(m-a)^2}{b}-1\right].
\]

这是高斯输出族内的预测 regret。若 P 非高斯且相应 KL 有限，则
KL(P||Q)=KL(P||G)+KL(G||Q)；现有 gap 未测量第一项。
跨超参数混合后的 GP 预测也可能非高斯，不能仅按先验名称判断预测是否单峰。
有限网格求积产生数值参照，连续先验积分的精度应逐区域验证。

固定网络均值 a 时，平方损失的条件风险为 r=v+(m-a)^2。
按 r 排序得到该固定预测器的最优选择集合；按 v 排序并使用 m 得到 Bayes 预测器的最优选择集合。
网络风险与固定预测器 oracle 的差衡量选择代价；后者与 Bayes oracle 的差衡量剩余均值预测代价。
三个量必须在相同任务、查询点与 coverage 上计算。

给定任意固定均值 a，高斯 NLL 对自由方差的最优值为 b*=v+(m-a)^2。
该恒等式说明均值误差可能扩大最优输出方差；它本身没有证明网络发生了特定隐变量归因。
网络输出的是总预测方差。拟合得到的 implied sigma 作为诊断量报告，附带投影残差与边界比例。

## 当前可用证据

- 两个先验、每个先验四个 width/steps 设置的数值结果和检查点均已保存。
- 部分条件的 gap 在 n=8 到 n=24 时增长；同时应报告预测误差的绝对值，避免把参照变强误读为网络变差。
- GP 的平均 gap 从 0.1048 降至 0.0477，跳变过程从 0.1081 降至 0.0768。
- 跳变先验的部分困难条件呈现均值项下降、方差项上升，需要独立训练复现与条件统计。
- 四个设置的 log-log 斜率只作为经验拟合；参数量乘步数是预算代理量。
- 已尝试的校准、委员会、加权、蒸馏与方差组合只支持各自实现及实验预算下的结论。
- 选择性预测代码提供按任务 bootstrap 的数值后验风险曲线；历史检查点上的小样本运行属于探索性证据。

## 完整补充矩阵

1. **数值参照**：先验上下界、低噪声、n=8/16/24、均匀与成对设计；同时比较端点等权、
   midpoint 及更细网格。报告 posterior moment 变化、gap 变化、低 coverage 风险变化。
   预定验收：参照引入的 gap 变化低于被声称效应的 5%；未通过的条件继续加密。
2. **训练随机性**：两个先验 × width 64/128 × steps 20k/40k × seeds 0–4，共 40 次独立训练。
   评估任务在模型间配对；把训练 seed 放在统计最外层。每格至少 200 个新任务，保存原始预测。
3. **输出头与预算解释**：同一主干和同一训练数据比较 Gaussian head 与可表示多峰的 mixture head；
   加入固定均值、独立方差拟合与显式不确定性分解对照。分别比较相同步数与相同实测耗时。
4. **决策后果**：报告 pooled 与 within-task 两种风险覆盖曲线，coverage 10/20/50/80/100%；
   同时报 NLL、MSE、区间覆盖率、区间宽度。预先指定困难区域，避免测试后挑选最差格子。
   预定主指标为 20% coverage 下固定预测器的 selection regret；要求独立训练 seed 的配对区间支持效应。
5. **外部有效性**：至少两个现成表格模型，在有自然环境划分的真实数据上验证部署含义，
   数据处理只拟合训练部分，校准使用独立数据。受控先验与真实数据分别报告。

完整矩阵的调度由 SCNet 实际 GPU 配额、单任务 smoke 吞吐与用户预算决定。
实验没有完成前，不把拟定矩阵写成论文结果，也不把未成功的局部干预推广为不可能性结论。
