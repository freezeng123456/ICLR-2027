# 选题范围：留下什么，砍掉什么

全部数字在 [`pfn-vs-its-own-bayes.md`](pfn-vs-its-own-bayes.md)。本页只做三件事：
把站得住的结论列清、把试过而不成立的列清、把范围收到一条线上。

## 收缩后的一条线

> **PFN 的预测不确定性不是它的后验不确定性；上下文越多这件事越糟；
> 而放大模型会单调地让它更自信——在原本不够自信的地方是改进，
> 在结构清晰、噪声低的地方是变坏。**

这条线的三个支点都在两个先验上复现过，而且都只能在有闭式精确后验的设定里测出来。
落点是不确定性：谁在用 TabPFN 的预测方差做决策，谁就受这一条影响；
不确定性分解那一支文献正在试图把偶然性与认知性分开，而这里说明偶然性那一份是被污染的。

## 站得住的结论

按证据强度排。每条只给一个锚定数字，其余在主文档。

| | 结论 | 锚定数字 | 复现范围 |
| --- | --- | --- | --- |
| 1 | **上下文越多，偏离它自己的贝叶斯最优解越远** | 跳变先验 30/32 个组合上升；高斯过程 20/32 | 两个先验、四个算力设置 |
| 2 | **网络把自己的逼近误差算进噪声那一维** | 隐含噪声偏高 1.19 倍（高斯过程）到 1.53 倍（跳变） | 两个先验、四个设置符号一致 |
| 3 | **算力单调地让网络更自信** | 方差对数之差逐格子变小：81/96 与 94/96 | 两个先验 |
| 4 | **算力在尖锐区域买不到东西** | 跳变先验最差格子 8 倍算力只降 4%；KL 方差项 0.1809 → 0.2614 单调上升 | 跳变先验的 10 个格子；高斯过程 0/96 |
| 5 | **偏离的价格可以量出来，但不是先验不变的** | 高斯过程指数 0.371（$R^2$ 0.983）；跳变 0.146 | 每个先验 2×2 四点，跨 8 倍算力 |
| 6 | **这个偏离顺手修不掉** | 五种做法逐一不成立，见下 | 见下 |

第 2 条与第 3 条合起来是机制：网络输出的方差要覆盖自身的均值误差（比值中位数在 1 附近），
所以多出来的那部分弥散不是后验的不确定性，是逼近误差；
而算力把这份弥散一路收紧，收到尖锐区域就收过头了。

## 试过而不成立的

留在这里是因为每一条都关掉一个方向，而不是因为它们有价值。

| 做法 | 结果 | 关掉了什么 |
| --- | --- | --- |
| 训练前可算的条件数 $\kappa = \lambda_{\max}((F+\Lambda)^{-1}G)$ | Spearman 0.135 / 0.174；误差方向与它相反（0.399 对零假设 0.5） | 「先验的信息几何决定偏离量级」整族 |
| 只靠模拟器采样估 $G$ | 比值 36.2 | 把上面那族搬到没有闭式的先验上 |
| 推理期输出修正（全局与依区域） | 留出 NLL 只降 0.0005 nat，而差距是 0.068 nat | 事后校正。网络已在先验平均 NLL 的最优点上 |
| 上下文切分的贝叶斯委员会 | 4.6 倍 | 用切分换精度。各份携带同一份信息，精度相加是重复计数 |
| 按偏离加权上下文点数 | 零和：最差格子改善 3%，$n=8$ 变差 13% | 「网络只是没见够长上下文」 |
| 等算力的精确目标蒸馏 | 1.50 倍 | 「瓶颈是目标方差」。瓶颈是步数 |
| 成对紧邻的上下文设计 | 摊销误差 0.58–0.72 倍，总误差反而 +0.17 nat | 用实验设计换摊销精度 |
| 两个模型的方差取较大者 | 跳变先验最差格子 0.585 倍，但高斯过程 2.044 倍；三个可部署判据都选错 | 「拿两个模型就能修」。要判断该不该用，需要精确后验 |

最后一条最值得记住：**增益是真的，选不出来。** 平均留出 NLL 必然选原始大模型
（网络本来就在这个目标上训出来的）；最差区域 NLL 两个先验都选它、包括有害的那边；
先验采样上的覆盖率指错区间。受损区域是先验里很薄的一片，没有汇总统计量把它分出来。

## 砍掉的部分

- **信息几何那一支**（$F$、$G$、$\kappa$、模拟器估计量）降为一条负面结果，
  不再作为主线的一节。它在主文档里保留，是因为四个候选量在 96 格上形状彼此不同、
  这是判别而非拟合，值得写进论文一段。
- **五条修法**压成一节，标题是「这个偏离顺手修不掉」。
  它的作用是证明现象是结构性的，不是提出方法。
- **上下文设计的取舍**压成一段。它是干净的受控结果，但不在这条线上。
- **宽 256 的第五个标度点**不做。标度律在收缩后是一节而不是头条，
  四个点、$R^2$ 0.983 够用；而且第 5 条已经说明这个指数不是先验不变的，
  再加一个同先验的点不改变这个结论。

## 下一个实验

这条线落在不确定性上，所以缺的是**决策层面的后果**：0.26 nat 的超额 KL 到底意味着什么。

选择性预测的风险覆盖曲线是最贴合的一个：按预测方差从小到大排序、逐步放弃高方差的查询点，
用精确后验能得到可达的最优曲线，用网络得到一条更差的。
两者之差就是不确定性用错的代价，而且可以按已有的 KL 拆分归因到方差项还是均值项。

不需要新的训练——十个检查点、两个先验、两套精确后验都在仓库里，只需要前向传播与排序。
按已有评估的规模，两个先验各 96 格 × 40 任务，与 `exp_hybrid.py` 同一量级。

判据先写死：若网络的风险覆盖曲线在低覆盖端（只保留最有信心的那部分查询点）明显差于精确后验，
且差距主要来自方差项，那么第 2、3 条结论就有了决策层面的代价；
若两条曲线贴合，说明这个偏离虽然可测，但不改变按不确定性排序的决策，
那么论文的落点要从「不确定性不可信」退到「偏离可测且随算力反常」。
