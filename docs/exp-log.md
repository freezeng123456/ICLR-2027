## 结果

### `exp_calib_baselines.py`（已跑完，n=50 = 25 种子 × 2 种标签器）

主指标 log loss，辅 ECE，准确率必须盯住。

**目标噪声 3%**（基准 ECE 已经只有 0.077，平均拟合 T=1.58）

| 方法 | log loss | ECE | 准确率 | 相对基准 t |
| --- | --- | --- | --- | --- |
| 基准 | 0.5290 | 0.0774 | 0.7647 | — |
| 温度缩放（60 个 ID 点） | 0.4968 | 0.0554 | 0.7647 | −4.4 |
| Platt（同上 60 点） | 0.4954 | 0.0591 | 0.7681 | −3.9 |
| 固定 T=2 | 0.5067 | 0.0716 | 0.7647 | −2.4 |
| 60 个 ID 点进上下文 | **0.3214** | 0.0425 | **0.8770** | −13.3 |
| 真实上下文注噪 50% | 0.8964 | 0.2192 | 0.4942 | +14.5（更差） |
| far-anchor η=15% | 0.4788 | 0.0627 | 0.7764 | −4.8 |
| far-anchor η=50% | 0.4912 | 0.0780 | 0.7808 | −4.1 |

温度缩放 vs far_50：Δll +0.0056（t=+0.7），打平。有干净 ID 标签时，把点放进上下文（id_extra）才是正确用法。

**目标噪声 30%**（基准 ECE 0.200，平均拟合 T=6.97；这是方法半篇真正该赢的格子）

| 方法 | log loss | ECE | 准确率 | 相对基准 t |
| --- | --- | --- | --- | --- |
| 基准 | 0.8616 | 0.1996 | 0.5361 | — |
| 温度缩放（60 个 ID 点） | **0.6922** | **0.0432** | 0.5361 | −11.7 |
| Platt | 0.7050 | 0.0760 | 0.5191 | −10.8 |
| 固定 T=2（无额外数据） | 0.7259 | 0.1063 | 0.5361 | −13.0 |
| 60 个 ID 点进上下文 | 0.7071 | 0.0875 | 0.5733 | −10.5 |
| 真实上下文注噪 50% | 0.8901 | 0.2174 | 0.4995 | +1.2 |
| far-anchor η=50% | 0.7237 | 0.0971 | 0.5477 | −12.1 |

温度缩放 vs far_50：Δll **−0.0315（t=−3.8）**，温度赢。固定 T=2 vs far_50：Δll +0.0022（t=+0.3），打平。far-anchor 的 ECE 相对基准大约腰斩（0.200→0.097），与上一轮一致，但不是因为 far 这个设计，一条 `p^(1/T)` 就够。

**判据对照**

1. 有 ID 校准标签时，温度缩放在 30% 噪声格子上**超过** far-anchor。方法不能写成「优于标准校准」。
2. 给真实上下文加噪**校准追不上、准确率明显更差**。远置 + 任务无关不是摆设：它把噪声信号和决策边界拆开了。
3. 没有 ID 校准标签时，固定 T=2 与 far_50 在 log loss 上打平。方法若要活，必须证明 far 在「不能 hold-out、也不能瞎猜 T」时仍有用，或者证明它改的是推断而不仅仅是温度。
4. 有干净 ID 标签时，点应该进上下文，不该拿去当 far-anchor。

剂量反应仍在：30% 目标噪声下 far 的 log loss 随 η 单调下降 0.792→0.768→0.735→0.724。这是机制证据，不是方法优势。

### `exp_real_calib.py`（11 张表，每张 10 个划分；测试最多 400 行）

同一套 50 训练 / 60 校准或对照。`id_extra` 与温度缩放用同一批 60 个 ID 点。

| 数据集 | base ll | temp | far_50 | id_extra | far vs base | far vs temp |
| --- | --- | --- | --- | --- | --- | --- |
| diabetes | 0.546 | 0.518 | 0.519 | **0.490** | −0.026 t=−5.3 | 打平 |
| credit-g | 0.632 | 0.592 | 0.566 | **0.530** | −0.066 t=−5.1 | far 赢 t=−2.8 |
| blood-transfusion | 0.549 | 0.528 | 0.514 | **0.501** | −0.034 t=−4.0 | 打平 |
| kc2 | 0.427 | 0.416 | 0.409 | **0.397** | −0.018 t=−2.5 | 打平 |
| phoneme | 0.455 | 0.447 | 0.451 | **0.414** | 打平 | 打平 |
| make_classification | 0.366 | 0.360 | 0.368 | **0.301** | 打平 | 打平 |
| make_moons | 0.316 | 0.310 | 0.296 | **0.187** | 打平 | 打平 |
| spambase | 0.293 | 0.293 | 0.297 | **0.222** | 打平 | 打平 |
| breast_cancer | **0.144** | 0.228 | 0.165 | 0.103 | far 更差 t=+3.2 | 打平 |
| wdbc | **0.138** | 0.179 | 0.144 | 0.102 | 打平 | 打平 |
| banknote | **0.022** | 0.046 | 0.034 | 0.006 | far 更差 t=+3.5 | 打平 |

读法：

- 有额外 ID 标签时，**全部**表都是把点放进上下文最好。不要拿真标签去拟合温度，更不要拿去当 far-anchor。
- 模型已经校准得很好的表（breast / wdbc / banknote，基准 ECE ≤0.024），η=50% 的 far-anchor 是过度干预，log loss 变差。温度缩放在这些表上同样会过拟合 T。
- 基准就偏自信的表（diabetes / credit-g / blood / kc2），far-anchor **不靠 ID 标签**就能把 log loss 拉下来，幅度不差于用了 60 个真标签的温度缩放；credit-g 上甚至更好，而且准确率从 0.693 升到 0.718。
- 给真实上下文加噪在所有表上都把准确率打到 ~0.45。远置 + 任务无关这一条，在真实表上同样成立。

方法半篇改写成：far-anchor 不是更好的校准器；它是**没有额外 ID 标签时**的噪声隐变量旋钮，只在模型已经过自信时该拧。机制半篇不依赖这一条。

### `exp_temp_on_train.py`（T 只在 30 个训练点上拟合，不额外要 ID 标签）

这是对温度缩放更公平的对照：few-shot 里你拿不出 60 个 hold-out 点。

| 目标噪声 | 方法 | log loss | ECE | 准确率 | vs far Δll |
| --- | --- | --- | --- | --- | --- |
| 3% | base | 0.535 | 0.077 | 0.758 | +0.052 t=+4.9 |
| 3% | temp on train（平均 T=0.25） | 1.296 | 0.196 | 0.758 | +0.813 t=+14.2 |
| 3% | 固定 T=2 | 0.512 | 0.071 | 0.758 | +0.030 t=+5.7 |
| 3% | far_50 | **0.483** | **0.059** | **0.777** | — |
| 30% | base | 0.865 | 0.197 | 0.540 | +0.142 t=+11.5 |
| 30% | temp on train（平均 T=0.26） | 2.253 | 0.371 | 0.540 | +1.531 t=+16.7 |
| 30% | 固定 T=2 | 0.727 | 0.105 | 0.540 | +0.005 t=+0.8 |
| 30% | far_50 | **0.722** | **0.098** | **0.554** | — |

训练点已经在上下文里，模型对它们过度自信，拟合出的 T≈0.25 会继续锐化，测试 log loss 爆炸。few-shot 里温度缩放没有可用的校准集。

固定 T=2 在 30% 噪声上与 far 打平，在干净任务上显著更差：T=2 无条件把 logits 除以 2，far-anchor 会跟本地上下文对打，干净任务上压得比较轻。这是「改推断」和「事后除一个常数」的差别，也是方法半篇还能留下的那一小块。

### 丢失检查点补训（已完成）

`eval_restored.py`，种子 2024，与原表同一套轴测试。数字是相关/斜率。

| 模型 | 尺度轴 | 噪声轴 |
| --- | --- | --- |
| A 12ℓ（原仓库） | +0.863 / +0.683 | +0.899 / +0.918 |
| B 12σ（原仓库） | +0.861 / +0.681 | +0.835 / +0.741 |
| C 12×12 @15k（重训） | +0.645 / +0.354 | +0.528 / +0.384 |
| C 12×12 @45k（备份） | +0.760 / +0.528 | +0.621 / +0.468 |
| A144 单隐变量 144ℓ（重训） | +0.906 / +0.750 | +0.907 / +0.732 |

原纠缠表里 C@15k 是 +0.636 / +0.347 与 +0.519 / +0.357，重训后差 0.01 量级（PyTorch CPU 反传不完全决定）。A144 明显强于同组合数的 C，45k 步的 C 仍追不上 A144。纠缠结论站住了。

`eval_gp_prior_tilt.py` 在重训的 `pfn_gp.pt` 上：PFN 最接近自己先验下的混合后验（RMSE 0.170）；远处 anchor 把隐含长度尺度从 0.482 掰到 0.369（波动）/ 0.757（平滑），与解析解相关 +0.729 / +0.749。机制半篇的 GP 底座可以复现。

`eval_misattribution.py` 用新的 C@15k：A 在噪声操纵下均值相关仍是 +0.802，B 在尺度操纵下标准差相关仍是 +0.931。错误归因签名还在；C 两个轴都更弱，与纠缠表一致。

干预方式的理论分类见 [`theory-interventions.md`](theory-interventions.md)。分类问题上拧噪声隐变量与温度缩放几乎同一族映射，这就是数字接近的原因；回归上同一干预会动均值，输出映射做不到。
