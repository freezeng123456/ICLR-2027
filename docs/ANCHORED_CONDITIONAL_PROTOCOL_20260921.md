# Anchored conditional-variance diagnostic

## Fixed protocol

The diagnostic uses only local training artifacts and the parameter predictions produced from them. It runs on CPU with one Torch thread. The two training checkpoints are `training_0/final.pt` and `training_1/final.pt`. The four dataset seeds are `600`, `601`, `602`, and `603`, giving eight training/dataset pairs.

For every pair:

- `G=64`, `dimension=8`, `M=4`, and `N=4096` independent WOR replicates per point;
- `u=[4, 1, 0.2, 0]`;
- one anchor point per time;
- eight non-anchor points per time;
- non-anchor offsets are fixed Rademacher directions generated with seed `717`;
- coordinate width is `(1-total_a)**(-1/2)`;
- the same WOR subsets are used for original and anchored controls;
- no reference integral, oracle parameters, or true theta is used in the estimator.

The model input is generated by the local `learned_sbi.dataset` helper. Each checkpoint is loaded through `learned_sbi.load_model` on CPU and converted through `learned_sbi.predict`. The script requires the `done` receipt to contain exactly `completed\n` and records SHA-256 hashes for the checkpoint, training configuration, training summary, predicted parameters, theta, and context.

## Compared controls

The original control uses `ExtensionModel` with `control_variance=model.variance`, which gives the exact-tail slope control. The anchored control uses `AnchoredTailModel` with its fixed six-iteration parameter-only anchor construction. Both controls receive identical point arrays and identical WOR subset arrays. The exact target drift and potential are obtained from the original model's `exact` method.

For every point and time, the script records raw drift and potential estimates for both controls. It reports empirical means, errors relative to the exact target, sample variances, standard errors, and the analytical WOR drift variance

```text
G^2 / (4M) * (1 - M/G) * sum_g (e_g - mean(e))^2 / (G - 1).
```

The analytical variance is a diagnostic comparison with Monte Carlo observations. It does not impose a hard performance assertion.

## Interpretation boundary

This is a mechanism-level conditional-variance diagnostic. It does not establish end-to-end accuracy, speed, training quality, checkpoint quality, or a universal variance improvement. The fixed checkpoint, dataset, grid, direction, batch, and replicate choices are protocol facts. No parameter is tuned from the observed results. CUDA, server execution, and any external data source are outside this run.
