# 锚点尾部控制的独立 GPU 确认协议

状态：2026-09-21，确认数据生成和采样前固定。本协议是在真实检查点的局部方差诊断之后追加；锚点参数保持原先规则，不以 CPU 开发单元的中途表现选择设置。

## 资源与此前实验

原机器 GPU 仍被另一项训练使用。旧机器的 CPU 开发试验保留为辅助记录；本组使用新机器在探索线及可分离结构诊断全部结束后的空闲 GPU，顺序运行。GPU 同时仅一个研究进程，float64，CPU 线程限制为一。新机器全部阶段的累计时间上限仍为四小时，本组只使用剩余预算，不终止其他任务。

原先当前线的 80/300 单元网格实验保持“输入已准备、GPU 未启动”的状态。锚点确认结果不冒充该网格实验的结果。CPU 开发试验若因相同问题已转入 GPU 验证而停止，其所有完成及部分输出保留，整体标记为部分完成，并全部排除本确认统计。

## 固定比较

五个原有最终训练模型 × 新数据种子 700–709，共 50 个问题。每个问题比较 full、tail_fixed、tail_anchored，合计 150 个单元。G=64，d=8，N=32768，K=2048，U=20，M=4，扩散系数一，ESS 阈值 0.5。时间网格为平方网格，全部方法使用相同目标、时间网格、精度和配对随机种子。执行顺序由种子 20260924 固定。

全量与原尾部方法使用已在探索线验证的快速 sigmoid 实现。锚点方法使用已验证的尾部控制估计式，保留每个因子的精确仿射斜率，只将截距设为参数确定的中心点处精确匹配值。中心点由仿射分布中心出发，固定六次 Newton 更新，步长截断 ±1、曲率分母下限 0.2。控制的构造不得读取真参数、参考积分或确认集评估结果。

运动、无放回子集与重采样使用三个独立随机流，种子偏移分别为 0、1000003、2000006；不同方法因祖先选择不同，不宣称路径逐项相同。

## 判据与解释

主要指标是相对学习后目标的平均坐标 W1。相对真实目标的 W1 单独报告。联合符号总变差、目标中心化的标准化非对角二阶矩、32 个固定随机投影的 W1 用于检查边际误差遗漏的问题。

“接近全量精度且明显更快”的预定门槛：锚点法减去全量法的平均 W1 差值，其单侧 95% 上界不超过 0.002；包含准备的平均时间比例，其单侧 95% 上界低于 0.8。使用 10000 次训练种子 × 数据种子的交叉配对 bootstrap，并报告固定五个模型的数据重采样区间、逐训练种子结果。五个训练模型限制置信区间的推广范围。

时间必须包括参数复制、锚点计算和缓存复制、每步更新、随机选择、重采样和最终结果传输；共同的一次性网络参数预测和参考积分属于输入/评估工作，独立记录。单次预热不计时。计数、运行时间、总体积分证书与实际误差分别呈现。

锚点准备每个时间点包含七次全因子残差值计算和六次解析导数计算，分别记录计数；这里的因子计数不等同于神经网络调用次数。运行时间包含重复 sigmoid 计算及全部缓存处理。无放回子集使用与快速原尾部基线相同的连续随机键排序规则。

所有 150 个单元保留，包括不利结果。保存完整配置、源码和检查点校验值、原始粒子及权重、逐步诊断、参考积分、总体证书和完成凭证。服务器独立重算及本地恢复验证均通过后，该组才记为完整验证。

本研究对象仍是坐标可分离的共享分量方差混合模型；网络仅预测一次参数。锚点构造和控制变量本身不宣称新颖性；可能的贡献是结合精确尾部保证、针对组合漂移及势函数的控制和实测成本结果，仍须对照既有研究。通过本组门槛不表示真实逆问题、任意神经 score 或非对角尾部上的普遍优越性。

公开原始来源的书目页与摘要已核查：Baker、Fearnhead、Fox、Nemeth 的 *Control Variates for Stochastic Gradient MCMC* 已研究用控制变量降低随机梯度方差，并在对数凹假设下讨论固定精度的计算成本（https://arxiv.org/abs/1706.05439；正式刊物 DOI 10.1007/s11222-018-9826-2）。Bardenet、Doucet、Holmes 的 *On Markov chain Monte Carlo methods for tall data* 也已经使用控制变量减少子采样推断成本，并明确讨论有利模型条件（https://www.jmlr.org/papers/v18/15-205.html）。这些来源足以排除“控制变量降方差本身是新的”这一表述；具体算法等价性和完整先前工作比较尚未完成。
