## 方法问题

检验由共同尾部曲率构造的可归一化参考分布能否改善退火采样的精度与成本。参考采用单高斯或有限高斯混合，参数只能来自可用因子模型和固定模式搜索，不能使用真值、精确后验或确认集评价指标。退火路径为 q^(1-beta) p^beta，保持完整密度比，采用可核验不变性的移动。

开发数据种子固定为 1400–1403，交叉二维／八维和两种噪声，共十六个问题。新确认数据种子固定为 1500–1519，共八十个问题；每个问题使用两组配对采样随机种子。开发期间不得读取确认评价结果。所有超参数在开发前列入有限配置清单，基线也获得相同数据上的参数选择机会。开发选择规则及确认比较细节须在 GPU 启动前写入 manifest。

准备参考、模式搜索、CPU/GPU 传输均计入采样时间；精确评价参考对所有方法共用并单独计时。保留每次因子评价次数、退火温度、接受率、有效样本数和原始样本。相同样本数和实际成本比较分别报告。

主要确认要求为：投影 W1 相对开发选择的强基线，配对单侧 95% 误差退化上界不超过 0.002；时间比的单侧 95% 上界低于 0.8。以二十个数据种子为独立重抽样单元，同时保留维度、噪声和配对采样重复。只有联合条件通过才允许相应性能表述。开发不满足门槛时仍保存全部结果，不扩大该候选的性能确认。
